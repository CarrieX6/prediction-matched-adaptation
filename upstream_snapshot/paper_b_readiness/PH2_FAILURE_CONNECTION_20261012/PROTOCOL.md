# PH2 failure-connection analysis

This post-result analysis uses the same deterministic five-model matched ensemble as the permutation-null interface analysis. Mahalanobis distance is estimated from the 609 Derm7pt case-level out-of-fold mean score vectors with Ledoit-Wolf covariance. Spearman associations with p_M-p_Cflex use 10,000 case bootstrap draws (seed 20261023). M-minus-reference logits are decomposed exactly in a reference-coded 12-coordinate parameterization of the seven simplex blocks. No PH2-specific fitting is performed.
